# Parrlo Translate · макеты iOS v5.3 (подготовка)

Это дизайн-макеты экранов iOS-приложения Parrlo Translate (версия v5.3: подписка, устройства, перевод в облаке, «Мой голос», Dynamic Type) — статическая HTML-страница для просмотра командой на RU/ES/EN; исходники макетов хранятся в закрытом репозитории, здесь опубликованы только финальные кадры, производственного кода приложения здесь нет, а тексты с пометкой «не утверждено» ещё проверяются.

**Статус:** публичный репозиторий макетов; публикация через GitHub Pages (`main`, корень репозитория).

**Превью (GitHub Pages):** https://askerina.github.io/parrlo-translate-mockups-prep/

## Структура

| Путь | Содержимое |
|---|---|
| `index.html` | Основные экраны iOS Translate v5.3 (одна HTML-страница, переключение кадров) |
| `fonts/` | Inter и Nunito (variable woff2) для корневого макета |
| `keyboard/` | Интерактивный прототип клавиатуры iOS/Android — см. [keyboard/README.md](keyboard/README.md) |
| `whatsapp-bridge/` | Прототип «Перевести в Parrlo» (Share Extension / WhatsApp) — см. [whatsapp-bridge/README.md](whatsapp-bridge/README.md) |
| `.nojekyll` | Отключает Jekyll на Pages для прямой раздачи статики |
