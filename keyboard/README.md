# Parrlo · клавиатура (iOS / Android) — макеты

Интерактивный HTML-прототип клавиатуры Parrlo: пишете по-русски — в чат уходит перевод на ES или EN; есть перевод скопированного входящего сообщения. **Прототип: переводы заранее заготовлены.** Это макет, не прод-код.

**Превью:** https://askerina.github.io/parrlo-translate-mockups-prep/keyboard/
Отдельный кадр без рамки: `index.html?shot=<id>` (например `?shot=kb-04-preview`).

| Файл | Что внутри |
|---|---|
| `index.html` | Все экраны, переключение слева; клавиши печатают, «Перевести» показывает предпросмотр, язык и тон переключаются |
| `parrlo-a.svg` | Парло, вариант A (анфас), поза «покой» — статический кадр из `parrlo-chat-mockups/alive-parrlo-front` |
| `fonts/` | Inter и Nunito (variable woff2), локально, без CDN |

## Кадры

**iOS · MVP-1 (iPhone 17, 393×852 pt)**
- `kb-01-ru` — раскладка RU, полоса Parrlo: Парло, «→ ES / EN», тон «Друг / Вежливо», «Перевести» (Light Green #2BC48A, текст Ink #0E1116)
- `kb-02-es`, `kb-03-en` — раскладки ES (с ñ) и EN; клавиша RU → ES → EN в нижнем ряду остаётся
- `kb-03s-space-swipe` — смена раскладки свайпом по пробелу (жест в процессе: палец, след, подпись «‹ RU · ES ›» сдвинута)
- `kb-04-preview` — предпросмотр перевода: подсказка Парло, карточка, «Изменить» / «Вставить»
- `kb-05-preview-long` — длинный перевод: 3 строки, прокрутка внутри карточки
- `kb-06-incoming-copied` → `kb-07-incoming-panel` — скопировали сообщение → «Перевести скопированное» → перевод на русский в панели (в поле не вставляется)
- `kb-08-no-full-access` — плашка «Включите полный доступ — без него клавиатура печатает, но не переводит.», кнопка ведёт **только в Настройки**
- `kb-09-app-enable`, `kb-10-app-full-access` — экраны приложения: включение клавиатуры и зачем полный доступ

**iPhone SE (375×667)** — `kb-11-se-ru`
**Android (412×915 dp)** — `kb-12-android-ru` (микрофон прямо в клавиатуре), `kb-13-android-listen` (запись в клавиатуре)

**На потом — на проверке правил App Store** (iOS, не входит в MVP-1)
- `kb-14-later-mic-key` → `kb-15-later-mic-app` → `kb-16-later-mic-return` — кнопка микрофона, экран диктовки в Parrlo с подсказкой «Вернитесь стрелкой ‹ вверху слева» (автовозврата нет), после возврата текст в предпросмотре клавиатуры.
- Причина: App Store Review Guideline 4.4.1 — клавиатура не может запускать другие приложения, кроме Настроек. Поэтому в основных iOS-кадрах микрофона нет. Кадры сохранены, ничего не удалено.

## Размеры

| | Клавиатура | Полоса | Ряды клавиш | Буквы |
|---|---|---|---|---|
| iPhone 17 | ~320 pt | 52 pt | 4 × 54 pt, зазор 10 | 26 px |
| iPhone SE | ~280 pt | 46 pt | 4 × 48 pt, зазор 9 | 24 px |
| Android | ~310 dp + 24 dp навигации | 52 dp | 4 × 52 dp | 26 px |

> **Высоту сверим с техпланом Parrlo App.** Цифры выше — заложенные в макет, не финальные.

- Предпросмотр и перевод входящего **заменяют ряды клавиш** внутри той же высоты; выше окна клавиатуры ничего не рисуется.
- iPhone с Face ID: под клавиатурой системный ряд iOS (глобус и диктовка) — нарисован условно серым, это не наша часть.
- Свой глобус в нижнем ряду показывается по `needsInputModeSwitchKey` (на Face ID iPhone система обычно возвращает `false` — тогда свой глобус скрываем; в кадре iPhone 17 оставлен для наглядности, на SE он нужен).

## Токены: градиент клавиатуры (v2.3, тёмная тема)

Фон окна клавиатуры на всех кадрах (iOS, SE, Android):

| Токен | Значение |
|---|---|
| `kbG0` | `#12161C` (Dark BG), позиция 0 % |
| `kbG1` | `#111D20` = #12161C + 6 % #00875C, позиция 45 % |
| `kbG2` | `#0F2826` = #12161C + 16 % #00875C, позиция 100 % |
| `kbGrad` | `linear-gradient(180deg, #12161C 0%, #111D20 45%, #0F2826 100%)` — сверху вниз |
| `kbGlow` | свечение за Парло: `radial-gradient(90×60 at 22,24, rgba(43,196,138,.20) → 0)`; пик ≈ #173932 |
| Системный ряд / навбар | сплошной `#0F2826` (продолжение нижнего стопа) |

Клавиши — Surface `#1C2026` + обводка `rgba(255,255,255,.09)`. Контраст (WCAG 2.x, посчитан скриптом):

| Пара | Контраст |
|---|---|
| Буквы #E8ECF1 на клавише #1C2026 | 13,79:1 |
| Подпись пробела #9AA4B2 на #1C2026 | 6,49:1 |
| Текст служебных клавиш #E8ECF1 на #2A3038 | 11,21:1 |
| Код языка #2BC48A на #2A3038 | 5,93:1 |
| #E8ECF1 на нижнем стопе #0F2826 | 13,09:1 |
| #9AA4B2 на #0F2826 | 6,16:1 |
| #2BC48A на пике свечения #173932 | 5,62:1 |
| «Перевести»: Ink на #2BC48A | 8,43:1 |

Все пары ≥ 4,5:1. Сама клавиша к фону — 1,05:1 (как и раньше к #12161C — 1,1:1): границу клавиш держит обводка, а не заливка.

## Токены: смена языка свайпом по пробелу

Как в Яндекс Клавиатуре. На пробеле подсказка `‹ RU · ES ›`: текущий язык #E8ECF1 (ярче), следующий #9AA4B2. Клавиша RU/ES/EN рядом остаётся.

| Параметр | Значение |
|---|---|
| Направление | влево → следующий (RU → ES → EN → RU), вправо → предыдущий |
| Порог | ≥ 40 pt по горизонтали, угол ≤ 30° от горизонтали; срабатывает один раз за жест, в момент пересечения порога |
| Короткий тап | пробел (если порог не пройден) |
| Подпись во время жеста | едет за пальцем ×0,5, не дальше ±40 pt |
| Анимация смены | новая подпись въезжает с 60 % ширины, opacity 0,2 → 1; **180 мс**, `cubic-bezier(.2, .8, .2, 1)` |
| Тактильный отклик | iOS: `UIImpactFeedbackGenerator(style: .light).impactOccurred()` в момент смены. **В клавиатуре-расширении работает только с полным доступом** (без него — без отклика). Android: `performHapticFeedback(KEYBOARD_TAP)`, без доп. разрешений |
| Reduce Motion | без сдвига и въезда — только смена подписи (в прототипе — переключатель справа) |

**Конфликт с курсором.** В системной клавиатуре iOS удержание пробела включает перемещение курсора (трекпад); пользователи к этому привыкли. Предложение:
- быстрый свайп (движение началось < 300 мс после касания) — смена языка;
- удержание ≥ 400 мс без движения → режим курсора (`adjustTextPosition(byCharacterOffset:)`), смена языка в этом жесте не срабатывает.

Альтернатива по формулировке владельца — удержание + движение тоже только меняет язык, курсора нет. Решение за Муратом (см. открытые вопросы).

## Бренд
Брендбук v2.3, только тёмная тема с мягким зелёным градиентом клавиатуры (токены выше): фон #12161C, клавиши Surface #1C2026, Ink #0E1116, Light Green #2BC48A; Inter (интерфейс) + Nunito Black (wordmark «Parrlo»). RU на «вы», ES на «tú». Мессенджер в кадрах условный, без чужого бренда.

## Названия тонов (RU / ES / EN)

| Ключ | RU | ES | EN |
|---|---|---|---|
| `tone.friend` | Друг | Amistoso | Friendly |
| `tone.polite` | Вежливо | Cortés | Polite |

ES и EN — предложение Parrlo Design, нужна вычитка Review Global перед релизом. Ширина чипа рассчитана на самое длинное слово («Amistoso», «Вежливо»), кегль и паддинги прежние.
