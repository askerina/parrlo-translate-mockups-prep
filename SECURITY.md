# Security

If you discover a security issue related to this repository or its published GitHub Pages mockups, please report it privately.

**Contact:** open a [GitHub Security Advisory](https://github.com/askerina/parrlo-translate-mockups-prep/security/advisories/new) for this repository, or reach the maintainer via the account [@MuratPod](https://github.com/MuratPod).

Please do not disclose security issues in public issues before they are addressed.
